# LCD_i2c_GSOE by dercrafter-168

## Introduction
This is a fork from the original "LCD_i2c_GSOE" library from the author Christopher Pepper.
All credits go to him and MbedOS (ARM Ltd.).
After the original author stopped maintaining the library,
I forked it to make it compatible with the newer MbedOS versions (including **Mbed CE**).

## Contributing
If you want to contribute to this library, please fork it and send me a pull request.
